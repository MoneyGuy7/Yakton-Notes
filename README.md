# Yakton Notes
Free, no-sign-in notes that live in the browser. Static site for Cloudflare Workers (`notes.yakton.net`).

- Multi-note editor: bold/italic/underline, H1/H2, bullet/numbered lists, ☐ checkboxes, undo/redo, search, word count
- Autosave to localStorage; export .txt/.md/.html; JSON backup and restore (sanitized on import)
- Landing pages generated by `scripts/build.mjs` (notepad, to-do list, journal, meeting notes) with FAQ schema, sitemap, robots
- Add a page: add an entry to `PAGES` in `scripts/build.mjs`, then `npm run build`

## Deploy
`npm install && npx wrangler login && npm run deploy`, then add custom domain `notes.yakton.net` in Cloudflare, and submit `https://notes.yakton.net/sitemap.xml` in Google Search Console.
